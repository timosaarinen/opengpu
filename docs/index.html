Finnish GPU

Explore an accessible approach to graphics and compute, from software experiments to future hardware. Share the ideas, question the tradeoffs, and let measured results guide the design.

The goal is fully dynamic graphics: worlds that can change at any moment, with intelligent reuse of work instead of mandatory offline lighting bakes.

ValoX API

A small, explicit interface for path tracing and machine-learning inference. Make useful computation easy to call while keeping application and presentation choices outside the API.

Start with practical workloads and clear behavior. Keep the interface portable as implementations and hardware evolve.

Early research and development. These are design goals, not claims of finished hardware or a stable API. This site is the public home for documentation and discussion.
